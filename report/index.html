What's inside

Executive summary

Plain language, business consequence first — auditors and non-technical founders both read this page.

Findings

Each with severity and rating rationale, evidence ID, reproduction steps, attack path (actor → action → consequence), and a copy-paste fix with post-fix verification steps.

Severity rubric

The rating method and definitions used in your report, so findings are comparable and defensible.

What you do right

Named explicitly. Auditors ask; it's honest — and it's the page your team likes reading.

Hardening notes appendix

Real observations without a full attack path — priced at zero, never inflated into fake findings.

Evidence ledger

Raw server responses, byte-counted, UTC-stamped — disproven hypotheses included. Any finding traces to raw evidence. This is what makes it auditor-ready.

Owner column

Your internal remediation tracker. We provide indicative effort estimates; you own assignment and status. We never participate in internal remediation.

Retest addendum

Findings move to verified-fixed / still-open in the ledger, with the retest dated and signed by us.

Methodology & coverage annex

Which test areas were performed, which were out of scope, which weren't — documented per engagement alongside the evidence ledger. A completed engagement is not a security guarantee, and the report says so.

A finding, as it ships

F-03 · MEDIUM · Password reset lacks rate limiting

Attack path
An attacker → submits 10,000 reset requests for a known user → token space narrows → account-takeover risk on predictable tokens.
Repro
6 reset requests for one account in 60 seconds; the 6th returns 200 and no 429.
Evidence
A2-P-14 (raw responses, 10,445 bytes / 10.2 KB, 2026-11-06T18:44Z)
Fix
Rate-limit the reset endpoint per-IP + per-account; 5/hour. (copy-paste nginx/express snippet per stack)
Verify
6th request within 1h returns 429; legitimate reset still lands.
Effort
~1 hr (our indicative estimate; you own the final estimate and the owner column)

Every finding ships runnable

The validator pack — evidence you can run yourself.
Each finding comes as a rate-limited, non-destructive script: ./F-03_validate.sh → exit 0 = fixed, 1 = still present, 2 = rig error. You can verify the fix yourself; our re-run stays the authoritative record. The validators are yours to keep and run anytime.
